# 📈 量化分析工作台 · Quant Studio

![CI](https://github.com/你的用户名/quant-app/actions/workflows/ci.yml/badge.svg)
（推送后把「你的用户名」替换成自己的 GitHub 用户名即可显示 CI 徽章）

一个**多市场通用、零第三方依赖、开箱即用**的量化 Web 应用：数据获取与存储、策略回测、实时信号盯盘、可视化看板，一次搞定。

- 后端：Python **纯标准库** `http.server`（无需安装 FastAPI/Flask）
- 计算：`numpy` + `pandas`（本机 DSH 自带 Python 已内置）
- 前端：原生 HTML/CSS/JS + 手写 Canvas 图表（**不依赖任何 CDN**，断网也能用）
- 存储：SQLite 本地行情缓存（标准库 sqlite3）

---

### 0. 标的输入：名称搜索 + 名称显示 + 自由日期区间

- **名称搜索**：标的输入框支持按**名称/代码/拼音**搜索（如输入"茅台"→贵州茅台、"腾讯"→港股腾讯控股、"螺纹"→螺纹钢连续），
  点击候选自动切换对应数据源并填入正确代码。
- **名称显示**：选中/回测后自动显示标的名称（600519→贵州茅台、RB0→螺纹钢连续、00700→腾讯控股、CUM→沪铜主连），
  实时信号条与 K 线标题均带名称。
- **自由日期区间**：回测设置中的「开始日期/结束日期」可任意限定回测区间（留空 = 全部数据）；
  区间内数据不足 20 根时会给出友好提示。

## 🚀 快速启动（30 秒）

双击 **`start.bat`**，或在项目目录执行：

```
python app.py
```

服务启动后会自动打开浏览器（默认 `http://127.0.0.1:8000`），
首次进入即自动用「模拟数据 + 双均线策略」跑一次回测，立刻看到效果。

> ⚠️ 运行环境需要 `numpy` 和 `pandas`。本机的 DSH 内置 Python 已自带
> （`C:\Users\Administrator\.dsh\dsh-runtimes\dsh-primary-runtime\dependencies\python\python.exe`），
> `start.bat` 会自动找到它；用系统 Python 则先执行 `pip install numpy pandas`。

#### ⚙️ 期货怎么填（国内）

| 类型 | 写法 | 示例 |
| --- | --- | --- |
| **连续合约**（回测最常用） | 品种代码 + 0 | `RB0`（螺纹钢连续）、`IF0`（沪深300股指）、`AU0`（沪金）、`CU0`、`M0` |
| **主力连续** | 品种 + M / 中文名+主连 / **品种 + 6666（或 0000）** | `RBM`、`CUM`、`沪铜主连`、`IFM`、**`AG6666`（沪银主连）**、`RB6666` |
| **次主力连续** | 品种 + S / **品种 + 7777** | `CUS`、**`AG7777`（沪银次主连）** |
| **具体合约** | 品种 + 年月 | `CU2506`、`RB2601`、`IF2611` |

- 主连 = 跟随成交/持仓最大的合约自动换月（东财）；次主连 = 主力合约的替补；连续 = 成交量加权拼接（新浪）。
- **`XX6666`/`XX0000` = 主连、`XX7777` = 次主连**（文华/同花顺/TickDB 等终端的数字后缀写法），已内置映射：
  东财主连/次主连数据优先，接口异常时自动用新浪连续兜底；大小写均可（`ag6666` = `AG6666`）。
- 具体合约东财优先，接口异常时自动切新浪。
- ⚠️ **加权指数暂无免费源**：`XX8888`/`XX9999`（文华、同花顺的指数/加权连续约定）会给出明确提示；
  研究时用主连/次主连/连续替代即可。

> `func(df, **params) -> pd.Series`（只做多返回 0/1，多空返回 -1/0/1），再调 `register()` 即可，
> 前端自动出现参数面板（多空策略传 `long_only=False`）。

### 2.2 杠杆 / 做空 / 两融机制（回测设置）

| 设置 | 说明 |
| --- | --- |
| **杠杆倍数** | 1~10 倍。杠杆 >1 时按两融模式模拟：借入额 = 名义市值 × (L−1)/L，上限 10 倍（保证金 10%，期货风格；A股两融实际约 2 倍） |
| **交易方向** | `只做多`（忽略空头信号）/ `只做空`（纯做空）/ `多空双向`。**只做空**时：多空策略只取空头信号；只做多策略自动**反转信号**（策略空仓→开空，持有→平空），任何策略都能做空 |
| **融资年利率** | 按借入额逐日计提利息（默认 8.35%，两融市场参考利率），计入净值 |
| **强平模拟** | 维持担保比例 =（净资产+负债）/负债 低于 130% 时按当日收盘价强制平仓；净值 ≤ 0 判定爆仓，记录强平次数 |

K 线图标记：B 买入 / S 卖出 / 空 开空 / 平 平空；交易明细标注多空方向。

### 2.3 两融数据看板

A股标的下，K 线图下方自动展示「两融资金」双轴图：**融资余额**（左轴，亿元）与**融券余额**（右轴），
数据来自东方财富数据中心（融资融券标的范围外自动隐藏）。融资 = 借钱做多，融券 = 借券做空。

### 2.5 🤖 AI 生成策略（自然语言自定义）

侧栏「**AI 生成策略**」面板：用一句话描述策略 → DeepSeek 大模型自动生成代码 → 自动校验 → 注册进策略库 → 立即回测。

**使用步骤：**
1. 到 <https://platform.deepseek.com> 免费注册，创建 API Key（新用户有免费额度）；
2. 把 Key 粘贴到面板（只存在你的浏览器里，不落盘；也可用环境变量 `DEEPSEEK_API_KEY`）；
3. 输入描述，如：*「5日均线上穿20日均线买入，跌破卖出，亏损3%止损」*、*「RSI小于30且放量时买入，RSI大于70卖出」*；
4. 点「✨ 生成并回测」，生成后可直接在面板里查看/复制生成的代码。

**安全机制：**
- 生成代码在**受限环境**校验执行：仅允许 pandas/numpy/math/内置指标函数，禁止网络、文件、os/sys 等系统调用；
- 子进程沙箱 + 15 秒超时，死循环/崩溃都会被拦截；
- 校验通过才注册进策略库；策略描述会发送给 DeepSeek API（请勿包含敏感信息）。

### 3. 回测引擎

向量化回测：持仓 × 收益率 − 手续费（换仓才收）→ 净值曲线。
输出指标：**总收益 / 年化收益 / 夏普比率 / 最大回撤 / 卡玛比率 / 交易次数 / 胜率 / 盈亏比 / 平均单笔收益**，并与「买入持有」基准对比。

### 4. 实时盯盘

- 模拟数据源：每 3 秒刷新一次价格与最新策略信号（买入/卖出/持有/空仓）。
- 真实数据源：每 20 秒拉取最新价与信号。
- 可一键开关盯盘。

### 5. 可视化看板

- **K 线图**：蜡烛 + 成交量 + 买卖/开平标记；滚轮缩放、鼠标拖拽平移、悬停查看 OHLC 与指标数值。
  - **底部全景缩略条**：整段行情的迷你走势 + 高亮窗口，**点击定位、按住左右拉动**即可平移 K 线（手机单指拖动、双指捏合缩放）；
  - 触屏支持：点按查看数据、单指拖动、双指缩放。
- **指标图系统**（K 线图上方开关按钮，分「主图 / 副图」两组，通达信风格，18 个常用指标）：
  - **主图叠加**：MA（5/10/20/60）、BOLL（20,2）、EXPMA（12/50）、BBI（3/6/12/24）、SAR（抛物线散点）
  - **副图窗格**：MACD（12,26,9，DIF/DEA + 红绿柱）、KDJ（9,3,3）、RSI（6/12/24）、
    **WR**（14，-20/-80 参考线）、**CCI**（14，±100）、**OBV**、**DMI**（+DI/-DI/ADX）、
    **BIAS**（6/12/24）、**ROC**（12）、**PSY**（12）、**MTM**（12）、**VR**（26）、**TRIX**（12,9）
  - 指标独立于策略：无论选什么策略都能任意开关；悬停十字线同步显示各指标当前值。
- **净值曲线**：策略净值 vs 买入持有，悬停查看数值。
- **交易明细表**：每笔买卖的时间、价格、收益率与盈亏。
- **两融资金图**：A股标的的融资/融券余额双轴图。
